# 诉捷 AI V0.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a locally runnable portfolio demo that carries a fictional 12345 complaint from mock AI structuring through tracked work order, reviewed reply, and closure.

**Architecture:** A React + Vite single-page frontend calls a FastAPI JSON API. FastAPI owns deterministic workflow rules and persists cases, timeline events, department replies, and generated replies in SQLite; a mock AI provider is enabled by default and validates structured outputs before the UI can use them.

**Tech Stack:** React, TypeScript, Vite, Vitest, Testing Library, FastAPI, Pydantic, SQLite, pytest

**Spec:** `examples/sujie-v0.1.md`

## Global Constraints

- All demo people, complaints, departments, dates, and records are fictional.
- AI routing remains a suggestion until a person confirms or edits the department.
- Generated external replies remain drafts until explicit human confirmation.
- Deadline and status calculations are deterministic application logic, never LLM output.
- Withdrawal is terminal and stops overdue calculation.
- Additional submissions retain linkage to the original case.
- Mock AI mode works without an API key; no RAG, authentication, external platform integration, or automatic sending.
