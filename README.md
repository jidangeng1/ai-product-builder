# AI Product Builder

A reusable skill/spec for turning product discussions into execution-ready Codex builds and portfolio evidence.

## What it does
ChatGPT/product discussion → execution brief → Codex implementation → run/test → acceptance review → iteration → portfolio packaging.

The first reference project is **诉捷 AI V0.1**, a fictional-data hospital complaint workflow demo.

## Files
- `SKILL.md` — orchestration rules
- `references/execution-brief.md` — handoff template
- `references/acceptance-checklist.md` — review gate
- `examples/sujie-v0.1.md` — first concrete execution brief

This repository contains process/specification material. It does not claim that 诉捷 AI is already implemented or deployed.
